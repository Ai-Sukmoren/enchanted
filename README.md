# Enchanted (web build)

Play in your browser: https://ai-sukmoren.github.io/enchanted/

A neon pixel-art isometric action RPG made with Godot 4.
- Computer: WASD to move, 1 for sword, Q for pistol, Space to dash, Esc for the menu.
- Phone: use the on-screen joystick and buttons, and turn the phone sideways.

This repository contains only the exported web build.
